CSS snippets I've written to work with Equicord.
They should work with Vencord as well; cannot guarantee compatibility with clients that just load Vencord/Equicord plugins, eg. Legcord, Goofcord.

## HighlightServers
Highlights server and folder icons when moused over, and highlights the current server you're in. Mouseover effect can be changed in the CSS file itself.

## NoActivities
Hides almost all activity statuses (member list, user profile, friend list) and the Games/Mutual Friends/Mutual Servers tab on a user's profile. Looks best without the WYSIWYG profile editor (will see what I can do about this)
