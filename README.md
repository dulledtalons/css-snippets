CSS snippets I've written to work with Equicord.
They should work with Vencord as well; cannot guarantee compatibility with clients that just load Vencord/Equicord plugins, eg. Legcord, Goofcord.

## HighlightServerIcons
Highlights server and folder icons when moused over, and highlights the current server you're in.

## No Activities
Hides almost all activity statuses (member list, user profile, friend list) and the games tab on a user's profile.
